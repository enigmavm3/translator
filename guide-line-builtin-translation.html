內 建 翻 譯 有 哪 幾 種

LINE 內建翻譯怎麼用？三種官方功能＋兩種常被誤認的做法

LINE 官方說明中心（2026-11-16 查證）列出的翻譯相關功能有三種：電腦版的右鍵翻譯訊息、手機版的圖片「轉為文字」翻譯、LINE 社群的自動程式翻譯。另外有兩種做法常被當成「LINE 內建」，其實不是，一併整理在後面。

做法 01

電腦版：在訊息上按右鍵 →「翻譯」

適用 Windows／Mac 電腦版 LINE。打開聊天室，在想翻譯的那則訊息上按滑鼠右鍵，選「翻譯」；左邊的下拉選單選原文語言（或選「偵測語言」讓它自動判斷），右邊選要翻成的語言。官方列出可互譯的語言包含繁體中文、簡體中文、英文、日文、韓文、泰文、印尼文、越南文、西班牙文、葡萄牙文、德文、俄文、阿拉伯文、印地文、波斯文、緬甸文，實際可選的目標語言會依原文語言而不同；菲律賓文沒有列在清單上。譯文顯示在你自己的畫面上，不會傳給對方。

做法 02

手機版：照片或圖片的「轉為文字」→ 翻譯

手機版 LINE 可以把聊天室裡的照片或圖片（例如藥袋、宿舍公告、菜單）轉成文字，再點「翻譯」。操作是：打開圖片 → 點「轉為文字」→ 用手指調整要辨識的範圍 → 在結果畫面下方切換語言，也可以複製或分享辨識出來的文字。可翻的目標語言包含繁體中文、英文、日文、韓文、泰文、印尼文、越南文等，實際可選項目依圖片原文語言而異。要注意，這是翻「圖片裡的字」，不是翻聊天室裡的文字訊息；字體花俏、字大小不一的圖片，辨識結果可能有誤。

做法 03

LINE 社群（OpenChat）：管理員開啟「自動程式」的翻譯

LINE 社群和一般群組是兩種東西。社群的管理員可以在社群設定的「自動程式」裡開啟翻譯，選擇要翻譯的語言，並套用給所有成員。但一般的 LINE 群組（你和家人、看護、同事那種）沒有這個選項。反過來說，LINE 社群也無法邀請翻譯機器人這類 LINE 官方帳號加入，所以兩邊的做法剛好相反：社群用內建自動程式，一般群組要加翻譯機器人。

常被誤認 04

手機長按訊息的「翻譯」：多半是手機系統或鍵盤的功能

不少人在手機上長按 LINE 訊息會看到「翻譯」，就以為是 LINE 內建。在 LINE 官方說明中心（2026-11-16 查證）裡，手機版聊天訊息並沒有列出長按翻譯的說明；你看到的「翻譯」，常見的是 iOS 選取文字後的系統翻譯、Android 的 Google 翻譯「輕觸翻譯」，或是手機鍵盤附的翻譯功能。這些工具確實能用，只是不是每支手機都有、介面各家不同，支援的語言也依手機而異，而且譯文一樣只有你自己看得到。請以你手機上實際顯示的選單為準。

常被誤認 05

LINE 官方翻譯帳號：一個帳號只翻一組語言

早年 LINE 推出過幾個官方翻譯帳號（例如中日、中英、中韓翻譯），加為好友後把它拉進聊天室，或直接傳訊息給它，就會回你譯文。限制是一個帳號只翻一組語言，而且以日文、英文、韓文為主；台灣家庭與工廠常用到的印尼文、越南文、泰文、菲律賓文，多半不在清單上。這些帳號目前是否還搜尋得到、是否正常運作，請以 LINE 內的搜尋結果為準。

限 制 在 哪

長按翻譯、右鍵翻譯的四個限制：你看懂了，對方還是看不懂

不論是電腦版右鍵、手機系統的長按翻譯，還是圖片「轉為文字」，這一類「內建翻譯」的本質都一樣：一次翻一句、翻給自己看。用在偶爾看一句很方便，用在每天要溝通的對象，會碰到四個限制。

限制一：譯文只有你看得到，對方那邊什麼都沒有

你把看護傳來的印尼文翻成中文、看懂了；但你回的中文，對方畫面上還是中文。要讓對方看懂，你得先把中文翻成印尼文，再複製、貼回聊天室傳送。一來一回，每句話都要多做兩三個動作。

限制二：每一句都要手動操作

一天幾句還好；每天要交代作息、用藥、排班、請假，每一句都要右鍵或長按一次，對話的節奏會一直斷掉。更常見的結果是，大家開始只講「最少的話」，該講清楚的事反而沒講。

限制三：群組裡每個人要各自翻

群組裡有家人、看護、仲介時，每個人都得自己翻看不懂的訊息。長輩和剛來台灣的看護通常不會操作這些選單，結果還是「已讀，但沒讀懂」。重要的事（回診時間、藥怎麼吃、哪天休假）最怕這種狀況。

限制四：手機上不一定有，電腦版才完整

LINE 官方說明裡完整的「翻譯聊天訊息」是電腦版功能；手機上要靠系統或鍵盤的翻譯，介面與語言支援依手機而異。而看護、移工幾乎都只用手機，等於對方那一端最缺的，正好是這個功能。

怎 麼 選

什麼時候用內建翻譯就好，什麼時候該把翻譯放進群組？

判斷方法很簡單：這個人，你一個星期要跟他講幾次話？

情況 A

偶爾一句：用內建翻譯就好

收到一則看不懂的訊息、想看一張藥袋或公告的照片、出國時問民宿老闆一個問題。右鍵或長按翻一下、拍張照轉成文字，不用加任何東西，也不用對方配合。

情況 B

每天都要講：把翻譯放進群組

家裡的外籍看護、工廠的移工、店裡的外籍員工，每天要交代作息、用藥、排班、請假，而且你會希望對方能用母語回問。這時候需要的不是「你看得懂」，而是「雙方都看得懂、都敢開口」。做法是把翻譯機器人當成一位成員邀請進 LINE 群組，之後你打中文，對方看到自己的母語；對方用母語回，你看到中文，兩邊都不用再多做任何一步。

並用

兩種做法不衝突，內建翻譯當輔助

加了群組翻譯之後，內建翻譯還是有用處：看護傳藥袋、公告的照片時，用手機的「轉為文字」看圖片上的字；在電腦前想對照某一句的譯文怎麼翻，也可以右鍵再翻一次。群組翻譯負責日常對話，內建翻譯處理照片和偶爾的對照。

常 見 問 題

關於 LINE 內建翻譯的常見問題

LINE 內建翻譯可以翻印尼文、越南文、泰文嗎？

可以，但要看是哪一種。電腦版右鍵翻譯訊息與手機圖片「轉為文字」的官方語言清單都包含印尼文、越南文、泰文；菲律賓文沒有列在清單上。手機上長按訊息看到的翻譯，多半是手機系統或鍵盤提供的，支援語言依手機而異。不論哪一種，譯文都只有你自己看得到。

LINE 長按訊息翻譯，對方看得到譯文嗎？

看不到。內建翻譯是把收到的訊息翻給你自己看，對方的畫面不會有任何變化。你回的中文對方一樣看不懂，要先翻成對方的語言、複製貼上再傳送。想讓雙方都直接看到譯文，要把翻譯機器人加進群組。

一般 LINE 群組可以開內建的自動翻譯嗎？

目前沒有這個選項。LINE 社群（OpenChat）的管理員可以在「自動程式」設定裡開啟翻譯；一般 LINE 群組沒有，要在群組裡自動翻譯，就要邀請翻譯機器人加入（翻譯小幫手是其中一種）。反過來，LINE 社群無法邀請機器人，所以家人與看護、工廠與移工請用一般群組。

已經加了翻譯小幫手，還需要用 LINE 內建翻譯嗎？

日常對話交給群組翻譯就好。內建翻譯可以當輔助：看護傳藥袋、公告的照片時，用手機的「轉為文字」看圖片上的字（翻譯小幫手不翻譯照片）；在電腦前想對照某一句的譯文，也可以按右鍵再翻一次。兩種做法不衝突。
